# 🤖 Crypto Predictor Bot

Телеграм-бот для прогнозирования движения криптовалют на 24 часа.

## 📋 Описание

Бот анализирует 100+ криптовалют и предоставляет прогнозы:
- Направление движения (рост/падение)
- Процент изменения
- Уровень уверенности

## ✨ Возможности

- 🔍 Анализ 100+ криптовалют
- 📊 Технический анализ (RSI, MACD, EMA, Bollinger Bands)
- 🔗 Ончейн-метрики
- 🌐 Рыночные индикаторы (Fear & Greed Index, доминация BTC)
- 📈 Автопрогнозы каждые 4 часа
- 📊 Статистика точности
- 💾 История прогнозов в SQLite
